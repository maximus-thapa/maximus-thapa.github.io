    🚀 React Performance Optimization

    This page covers key techniques and concepts for optimizing performance in React applications.

    🧠 Goal (Bloom’s Level: Analyze → Apply → Create)

    • Understand why and when performance problems happen in React.
    • Learn to use memoization, code splitting, lazy loading, and other tools effectively.
    • Build habits to think about performance while building apps.

    📌 1. Why React Can Be Slow

    React apps can slow down because of:

    • Unnecessary re-renders
    • Large bundle size (slow page load)
    • Expensive computations during render
    • Slow list rendering (e.g. long arrays)
    • Too many reflows/repaints in the DOM

    ⚡ 2. Key Optimization Techniques

    🔄 Memoization with React.memo

    const Button = React.memo(({ onClick, label }) => {
  console.log("Button rendered");
  return <button onClick={onClick}>{label}</button>;
});

    ✅ Prevents re-render if props didn't change.

    🧠 Deliberate Practice:

    • Create a parent component and wrap a child in React.memo.
    • Pass both constant and changing props. Observe render behavior.

    🧠 useMemo – Cache Expensive Computations

    const sortedList = useMemo(() => {
  return heavySortFunction(items);
}, [items]);

    ✅ Prevents recalculating unless items change.

    🧠 Feynman Check:

    "useMemo helps React avoid re-running slow logic when the inputs haven't changed."

    🔁 useCallback – Stable function references

    const handleClick = useCallback(() => {
  doSomething();
}, []);

    ✅ Avoids unnecessary re-renders when functions are passed as props.

    ⏳ Lazy Loading Components

    const LazyComponent = React.lazy(() => import("./HeavyComponent"));

<Suspense fallback={<Spinner />}>
  <LazyComponent />
</Suspense>;

    ✅ Speeds up initial load time by splitting bundles.

    🧠 Active Recall:

    • What's the difference between React.lazy and dynamic import()?
    • What’s the fallback UI for?

    🧱 Code Splitting with Webpack + React

    • React.lazy handles component-level splitting.
    • Tools like Webpack, Vite, and Next.js handle route-based splitting.

    🚥 Windowing Long Lists: react-window or react-virtualized

    import { FixedSizeList as List } from "react-window";

<List height={500} itemCount={10000} itemSize={35} width={300}>
  {({ index, style }) => <div style={style}>Row {index}</div>}
</List>;

    ✅ Only renders what's visible — ideal for huge lists.

    🧪 3. Measuring Performance

    🔧 Use React DevTools Profiler

    • Shows component re-renders and why they happened
    • Helps track unnecessary renders

    Practice: Profile a list with and without memoization.

    📏 use useEffect to measure render time

    useEffect(() => {
  const start = performance.now();
  // ... render logic
  const end = performance.now();
  console.log("Render took", end - start);
}, []);

    Can I load this component lazily?
    Am I rendering unnecessary elements in a list?
