    🏗️ System Design

    System Design is about building scalable, reliable, and maintainable software architecture.

    🧱 Core Concepts

    Concept Use for
    Load Balancing Distribute traffic
    Caching Reduce repeated computation
    Database Sharding Scale databases horizontally
    Rate Limiting Control abuse, protect backend
    Message Queues Async task processing
    CDN Serve static content fast

    🧩 Design Process

    1. Understand the requirements (functional + non-functional)
    2. Define system APIs (CRUD, streaming, uploads)
    3. Choose storage (SQL/NoSQL)
    4. Handle scale (load balancer, cache, replicas)
    5. Add observability (logs, metrics, errors)

    🧠 Example: Design a URL Shortener

    • API: POST /shorten, GET /:shortId
    • DB: Store shortId → URL mapping
    • Cache: Redis for fast lookup
    • Rate Limit: One shorten request per second
    • Scalability: Horizontal scaling of API servers
